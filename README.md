# 4K Projects – About page replica

1:1 static replica of <https://4kprojects.com/about-us> (a Framer site). The page's
interactions run locally on [Motion](https://motion.dev) (the engine behind Framer Motion)
and [Lenis](https://lenis.darkroom.engineering), with static data and no runtime requests
for code or data.

```
about-us.html                  page markup (Framer SSR output) + menu panel <template>
package.json                   dev dependencies: motion, lenis
scripts/vendor.js              copies the browser builds into assets/js/vendor
assets/
  css/
    fonts.css                  @font-face rules (DM Sans, Satoshi, Inter, …)
    framer.css                 Framer SSR component styles (generated, minified)
    lenis.css                  Lenis smooth-scroll base styles
    menu.css                   menu link styles (the runtime injected these on open)
    overlay-gallery.min.css    image lightbox (vendor: pin.supply)
  js/
    vendor/                    motion.js, lenis.min.js (generated by `npm run vendor`)
    data/content.js            static data: team bios, FAQ answers, counter target
    site/
      motion.js                adapter over Motion + scroll/in-view helpers
      smooth-scroll.js         Lenis, configured like Framer's Smooth Scroll (2s)
      text-effects.js          word/line "appear" text reveals
      scroll-effects.js        hero fade, hide-on-scroll-down, menu colour by section
      slideshow.js             hero slideshow (autoplay, drag, infinite loop)
      counter.js               "22+ ARTISTS" counter
      team-cards.js            team card hover with bio
      faq.js                   FAQ accordion
      menu.js                  burger menu (variants, overlay, panel)
      buttons.js               underline button hover ("See our work")
      main.js                  entry point
    overlay-gallery.min.js     image lightbox (vendor: pin.supply)
  icons/                       UI icons (carousel arrows)
  images/                      brand/, showcase/, team/
```

All scripts are classic `defer` scripts sharing a `window.FourK` namespace, so the page
also works when opened straight from disk (`file://`).

## Animations

Timings, easings and springs are copied from the original Framer components and passed
to Motion unchanged, e.g. `{ type: 'spring', bounce: 0.2, duration: 0.4 }` or
`{ duration: 0.6, ease: [0.44, 0, 0.56, 1] }`. Scroll-linked logic (hero fade, menu colour
per section, hide on scroll down) is ported from Framer's runtime.

To update the libraries:

```bash
npm install
npm run vendor
```

## Content

Hover and open states render text that is not in the saved markup: the team bios
(shown when hovering a card) and the FAQ answers (shown when a row opens). It lives in
`assets/js/data/content.js`. Bios are keyed by the card's name and answers are matched
by exact question text, so keep those in sync with `about-us.html` when editing.

## Styling conventions

Match the units the site already uses. Do not convert them.

- **px** for all sizes, spacing, radii and font sizes. The site uses no `rem`.
- **em** only for `letter-spacing`.
- **vh / dvh** only for full-viewport heights. **fr** for grid tracks. **%** for fluid widths.
- Breakpoints: desktop `min-width: 1200px`, tablet `810px – 1199.98px`, phone `max-width: 809.98px`.

## Known gaps

- The saved markup is a desktop snapshot. Some components only kept their desktop
  variant (e.g. the menu is wrapped in `ssr-variant hidden-1av14ed`), so they are hidden
  below 810px. Phone variants would need to come from the live site's server HTML.
- Fonts, responsive `srcset` images and favicons still load from `fonts.gstatic.com` /
  `framerusercontent.com`, as on the live site. The local image files are `src` fallbacks.
- The menu links point to the live site, except About.

## Notes

- Keep the two inline `<style data-framer-html-style>` blocks inside `#main`; they set the
  page background.
